<h3 align="center">oursnever</h3>
<p align="center">Nothing is ours forever.</p>

---

An independent engineering lab building **open-source instrument software**: precise tools to measure, control and understand complex systems, agents included.

Everything we make is released, documented and handed over, so it outlives the people who built it.

### Work

| | |
|---|---|
| **stippla** | Images, video and webcam into animated ASCII and halftone art. Tiny `.ascii` files that embed anywhere and play in terminals. |
| **proof3d** | Claude Code builds 3D assets in Blender, with proof: spec, re-runnable build, quality report, cost ledger. |

### Principles

- Open source by default.
- Measured, not claimed.
- Small, sharp instruments over platforms.
